# SIH 26038 Backend

This repository area is reserved for the SIH 26038 machine-learning backend and its deployment surface.

- `data/` — raw, processed, and externally sourced data assets.
- `configs/` — configuration files for training, evaluation, inference, and deployment.
- `training/` — future datasets, preprocessing, model, loss, training, evaluation, explainability, and shared utility code.
- `experiments/` — experiment outputs and tracking artifacts.
- `checkpoints/` — training checkpoint files.
- `models/` — saved PyTorch and ONNX models plus model metadata.
- `inference/` — future inference-pipeline code.
- `app/` — future FastAPI API, schemas, services, and application utilities.
- `tests/` — unit and integration tests.
- `docker/` — future containerization assets.
- `notebooks/` — exploratory and analysis notebooks.
- `docs/` — backend documentation.
- `scripts/` — operational and maintenance scripts.
