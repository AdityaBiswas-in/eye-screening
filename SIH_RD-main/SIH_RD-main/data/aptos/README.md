# APTOS 2019 Blindness Detection

Role: primary five-class diabetic-retinopathy grading dataset.

Official source: <https://www.kaggle.com/competitions/APTOS2019-blindness-detection/data>

Acquire this dataset manually and legally under the competition terms. Do not commit raw files to Git. Configure its local root through `APTOS_DATASET_ROOT` or `configs/datasets.toml`.
